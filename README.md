# Contradiction-Aware Multi-Document Summarizer

An automated NLP pipeline and interactive dashboard that analyzes multiple conflicting news reports about the same event, extracts atomic claims, clusters them by topic, classifies factual stances (Agreement vs. Contradiction), and synthesizes a structured report highlighting **Confirmed**, **Disputed**, and **Unconfirmed** facts.

---

## 📌 Overview & Architecture

When multiple media outlets cover a fast-moving breaking news event (e.g., natural disasters, geopolitical events), initial reports often present conflicting casualty figures, dates, government statements, and impact assessments. Traditional summarizers blend these into a single narrative, which conceals contradictions or creates factual inaccuracies.

This project implements a **Contradiction-Aware Summarizer** that explicitly preserves attribution and separates conflicting statements side-by-side.

### Pipeline Stages
1. **Atomic Claim Extraction (`src/01_extract_claims.py`)**:
   - Uses Groq LLM (`qwen/qwen3.8-27b`) to parse unstructured source articles into atomic, verifiable factual claims with source attribution.
2. **Clustering & Stance Classification (`src/02_cluster_and_classify.py`)**:
   - Embeds claims using `sentence-transformers` (`all-MiniLM-L6-v2`) and groups claims about the same fact using Agglomerative Clustering.
   - Evaluates cross-source claim pairs for stance (`agree`, `disagree`, `discuss`, `unrelated`) using an LLM classifier.
3. **Structured Summary Generation (`src/03_generate_summary.py`)**:
   - Generates a markdown report separating:
     - 🟢 **Confirmed Facts**: Multi-source agreement.
     - 🔴 **Disputed Facts**: Direct contradictions between sources with side-by-side attribution.
     - ⚪ **Unconfirmed / Single-Source Claims**: Reported by only one source.
4. **Interactive Dashboard (`app.py` / `src/04_app.py`)**:
   - Streamlit web interface allowing users to upload text files, trigger the analysis pipeline, and explore the interactive summary.

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.10+
- A Groq API key ([Sign up at console.groq.com](https://console.groq.com))

### 2. Installation
Clone the repository:
```bash
git clone https://github.com/aditya-hariom/news_summary.git
cd news_summary
```

Create a virtual environment:
```bash
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

### 3. Environment Setup
Copy `.env.example` to `.env` and fill in your Groq API key:
```bash
cp .env.example .env
```
In `.env`:
```env
GROQ_API_KEY=your_groq_api_key_here
```

---

## 💻 Usage

### Option A: Run via Streamlit Web App
Launch the interactive web UI:
```bash
streamlit run app.py
```

### Option B: Run the Pipeline via CLI
Run each step sequentially:
```bash
# Step 1: Extract atomic claims
python src/01_extract_claims.py

# Step 2: Cluster claims and classify stance
python src/02_cluster_and_classify.py

# Step 3: Generate the structured summary
python src/03_generate_summary.py
```
Output files will be saved in the `output/` directory:
- `output/claims.json`
- `output/clusters_with_stance.json`
- `output/final_summary.md`
